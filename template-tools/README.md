# template-tools · 学术模板复刻

把现成的学术 PPT 模板转成**可编辑占位版**：删掉前 3 页教程页，正文占位化，图片/图表留框，校徽交给用户在母版里手动替换。

## 一、当前成果

`effects/academic/templates/学术模板1/reference/` 下有六套「学术蓝」导航版式（每套 23 页）：

| 模板 | 说明 |
|---|---|
| 学术蓝-导航栏1–5 | 顶部导航条版式 |
| 学术蓝-导航栏6 | 左侧竖排导航版式 |

## 二、两个阶段（重要）

| 阶段 | 做什么 | 谁做 |
|---|---|---|
| **建库阶段**（一次性） | 删前 3 页、占位化、图片/图表留框 → 六套模板入库 | 已经完成，见 `reference/` |
| **调用阶段**（每次做 PPT） | 选色 → 选版式 → 给文案与图片 → 填进占位 | 见第四节 |

**调用时不需要再删页、也不需要再占位化**——模板已是占位版，直接填。

## 三、建库阶段的六步流程（rebuild.py，已完成，备查）

```bash
python template-tools/tools/rebuild.py 源.pptx 输出.pptx
```

| 步骤 | 规则 |
|---|---|
| ① 删前置说明页 | **视情况**：只有当开头若干页是「使用教程 / 说明页」时才删，页数由用户确认（本次学术蓝是 3 页）；正文页不能删 |
| ② 其余原样 | 版式、装饰、图形全部保留 |
| ③ 文字 | **前 5 页**与**尾页**：只把标题改「标题」；内容页：导航栏→「标题」、页面标题→「标题」、其余→「文本」 |
| ④ 图片 | 删除并在原位留「图片」虚线框；宽 ≥1100 的背景图、<200×150 的小装饰**保留** |
| ⑤ 图表 | 删除并在原位留「图表」虚线框 |
| ⑥ 校徽 | **不做自动替换**，由用户在【视图 → 幻灯片母版】手动换（见下） |

## 四、调用阶段的流程（每次做 PPT 按这个走）

> 触发词：用户说 **「PPT启动」** 才开始问，没触发不动文件。

```
① 选色      学术蓝 / 学术红 / 学术绿 / 学术紫
② 选版式    导航栏 1–6（1–5 顶部导航，6 左侧竖排导航）
③ 给素材    每页的标题、正文、配图（图片按页给）
④ 我填充    一条命令把文案与图片写进占位
⑤ 校徽      用户在【视图→母版】里手动换一次
```

第 ④ 步命令：

```bash
python template-tools/tools/fill_template.py 模板.pptx 内容.json 输出.pptx
```

`内容.json`：

```json
{
  "school": "北京大学",
  "sections": ["研究背景", "研究目标", "研究方法", "关键技术", "已开展工作", "进度安排"],
  "pages": {
    "1": {"title": "封面主标题", "texts": ["副标题"]},
    "7": {"title": "研究背景",
          "texts": ["正文第一段", "正文第二段"],
          "images": ["img/fig1.png"]}
  }
}
```

规则：
- `nav_offset`：导航从第几个框开始填（模板6 需试 0/1）
- 封面/信息页可给 `subtitle`；内容页灰条默认留空
- 导航名建议 **≤6 字**（超过会在顶部/左侧标签里折行，脚本会提示）
- `sections` 按导航栏位置顺序填入，自动缩字号防溢出
- 每页第一个「标题」→ `title`
- 「文本」按顺序对应 `texts`
- 「图片」按顺序对应 `images`（等比铺满、居中裁剪）
- 「图表」占位留给用户贴图表

## 五、校徽：交给用户手动换

模板里保留原校徽（或残留占位），按官方教程处理：

1. 菜单【视图】→【幻灯片母版】
2. 选中要改的版式页 → 点中校徽 → 【插入】自己的校徽
3. 深色底（如左侧导航栏）用**白色反白版**，浅色底用**彩色版**
4. 关闭母版视图，全篇生效

> 为什么不自动做：模板里的校徽常与导航图标混在同一区域，脚本难以可靠区分，容易误删导航项。**手动换一次最安全**。

## 六、已知可复用工具

| 工具 | 用途 | 注意 |
|---|---|---|
| `rebuild.py` | 六步重建（推荐） | 输出新文件，不覆盖源文件 |
| `scrub_template.py` | 早期版本：更激进的占位化 | 历史产物，规则已被 rebuild.py 取代 |
| `fill_template.py` | **调用阶段填文案与图片**（推荐） | 占位版模板专用 |
| `audit.py` | 校验：未占位文本 / 占位漂移 / 漏占位 | 建议每次产出后跑一遍 |
| `swap_by_name.py` | **按对象名称**替换某处图片 | 安全，不删任何对象 |
| `logo_swap.py` / `dedupe_logo.py` | 早期自动换校徽尝试 | **已弃用**，按坐标删除会误伤导航图标 |

## 七、经验教训（务必遵守）

1. **不要按坐标删对象**。曾经用「x<400 且 160≤y≤460」删所谓"多余校徽"，把左侧导航栏第一个图标删了。
2. **定位要按语义（不是按位置）**：
   - 语义定位 = 看对象"是什么"：文字写着「校徽」的那个框、名字叫 `矩形 11` 的那个对象、`slideLayout3` 里那个组合
   - 位置定位 = 看对象"在哪"：x/y/宽高落在某范围内就算目标
   - 为什么位置不可靠：导航图标、校徽、装饰图形常常挨在一起，坐标区间会同时命中多个对象；
     一旦"删"就误伤，而"改"则可能改错一片。
   - 结论：**能按名字/文字找到的，绝不按坐标找；需要删除时，先打印清单确认再删。**
3. **交付前必须全页渲染**，不能只抽检两三页。
4. **每次输出新文件**，不覆盖用户已手调的版本。
5. 改完跑 `audit.py`，确认「未占位文本 / 占位漂移 / 漏占位」为 0（目录页编号 01–06 属预期保留）。
