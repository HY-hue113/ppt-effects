## 结构

## 动画

```

  路径 5 点：M 0 0 → L 0.139 0.629 → L 0.868 0.361
             → L 0.380 0.085 → L 0.380 0.086
旋转：animRot by="21600000"（360°）
缩放：animScale + set ×3
时长：1000 / 1500 / 2500 / 3000 / 4000 ms
```

## 做法（换素材）

1. 复制 `reference/效果15.pptx`
2. 换 **背景图**：改 `p:bg` 里 `a:blip` 的 `r:embed`（在 `slide1.xml.rels` 换 Target）
3. 换文字：改 `文本框 1/2` 的 `a:t`
4. 形状 149 与动画**不要动**——路径是相对坐标，改形状尺寸会破坏巡游轨迹

## 坑

1. **形状是大画布**：80×80cm 定位在负坐标，看起来“跑出画布”是正常的
2. **背景不是纯色**：是图片填充 + `a:lum`，换图后亮度会继承，注意别把 `a:lum` 删掉
3. **路径是 relative**：`pathEditMode="relative"`，数值是相对形状尺寸的比例，不随画布变化
4. **动画目标按 id 绑定**（150/2/3）：删除或重建对象会导致动画失效
5. 转换的 SVG 形状无法再拆成单张图片，要换图案必须重新导入 SVG 转形状
