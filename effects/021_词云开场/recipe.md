# 效果21 · 词云开场

## 一句话

单页开场：标题 + 短句引子 + 3 条短句 + 7 个关键词，文字从画布左侧依次飞入并旋转，形成“词云炸开”的开场。

## 文本框清单（12 个）

| 名称 | 字号 | 框尺寸 | 字数 | 作用 |
|---|---|---|---|---|
| 标题 | 115pt | 350×195 | 弹性，建议 2–8 字 | 主题名 |
| 短句引子 | 80pt | 467×138 | **4–7 字** | 副标题 / 核心主张 |
| 短句1 | 72pt | 284×126 | **4–5 字** | 递进第一句 |
| 短句2 | 72pt | 284×126 | **4–5 字** | 递进第二句 |
| 短句3 | 72pt | 284×126 | **4–5 字** | 递进第三句 |
| 关键词1–7 | 44pt | 353×80 | **2–3 字** | 词云散点 |

## 动效

| 项 | 数量 |
|---|---|
| 运动路径 | 13 |
| 旋转强调 | 11 |
| 淡入/出现 | 1 |
| 页面切换 | 无（单页） |

文字初始位置在画布外（x 为负），靠路径飞入；**不要改文本框位置**，那是动画终点。

## 使用流程

1. 用户给主题或原文
2. 我按上表提炼：标题 → 短句引子 → 3 条短句 → 7 个关键词
3. **先把文案给用户确认**，再替换进 PPTX
4. 替换时只改文字，不动位置/字号/字体
5. 渲染一页确认，再定稿

## 坑

- 标题过长溢出画布
- 关键词超 3 字会换行，词云散点会散架
- 12 个框要全换，否则残留“关键词3”这种占位
- 单页无切换，靠动画；放映即见效，无需 F5 翻页

## 单行规则（2026-11-27 修正）

**所有文本框只显示一行；文字变长时加长文本框，不换行、不缩字号。**

做法：量字宽 → 新框宽 = 字宽 + 24px → 左缘左移一半（保持视觉中心）→ 校验右缘 ≤1280。

| 槽位 | 字号 | 可用字数 | 加长后框宽 |
|---|---|---|---|
| 标题 | 115pt | 4 字 | 350 → 636px |
| 短句引子 | 80pt | 5 字 | 467 → 554px |
| 短句1–3 | 72pt | 4 字 | 284 → 404px |
| 关键词1–7 | 44pt | 2–4 字 | 353（原框够用） |

示例（主题：介绍 DeepSeek Harness）：

| 槽位 | 文案 |
|---|---|
| 标题 | 驾驭智能 |
| 短句引子 | 让模型动手 |
| 短句 | 一次会话 / 一套工具 / 一群代理 |
| 关键词 | 模型 / 技能 / 智能体 / 编排 / 插件 / 工作流 / 本地 |

## 运动路径规则（2026-11-27 用户要求）

| 对象 | 起点 | 终点 |
|---|---|---|
| 标题 | 画布内，水平居中 | 不动 |
| 短句引子 | 画布外左侧 | **水平居中**（终左 = 640 − w/2） |
| 短句1–3、关键词1–7 | 画布外左侧（x + w ≤ 0） | **画布外右侧**（x ≥ 1280） |

原因：路径动画在开始与结束时会停留静帧，若端点落在画布内就会看到文字“卡”在边缘。

计算：

`
起点 x = -(w + 60)
终点 x = 1280 + 60（飞越项）／ 640 - w/2（引子）
dx = (终点 x - 起点 x) / 1280
`

校验：起右 ≤ 0、终左 ≥ 1280；引子终点的中心误差 ≤ 4px。

## 定稿说明（2026-11-27）


eference/参考件-词云开场.pptx 为**本效果唯一参考件（终版）**，同时具备：

- 12 个文本框单行显示，文字变长时加长文本框（居中扩展）
- 短句引子起点在画布外、终点水平居中
- 短句1–3、关键词1–7 起点与终点全部在画布外
- 标题静止、居中
