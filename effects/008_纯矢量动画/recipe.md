## 为什么叫"纯矢量"

整份 33 页只有 3 张图片（两条装饰竖条 + 一个小图标），其余全是形状、文本框、纯色块。所以：

- 文件只有 0.5 MB（同体量图片模板通常 40–50 MB）
- 改色改字零成本，投影不卡
- 但不适合"照片驱动"的视觉，强行塞图会破坏它的清爽感

## 复用方式

**只用文字替换，不动版式**：`tools/remake_uni.py` 里维护一张 `REPL` 表，键是页码，值是（原文片段 → 新段落列表）。脚本会保留原 run 的字体字号，绿卡上的文字自动转白。

```bash
python tools/remake_uni.py
```

## 坑

1. **不要整段重写封面**：封面是「大学生 / 职业生涯规划」两个段落，塞成一整句会折行压到底线以下。
2. **目录会折行**：「自我认/识」「环境分/析」是模板自带问题（文本框宽度不够），要改就加宽文本框，别改字。
3. **改目录必须同步改章节页**，否则目录与章节不一致（本模块因此保留模板原词：自我认识 / 评估与调整）。
4. **绿卡上的文字要用白色**（`RGBColor(0xFF,0xFF,0xFF)`），沿用原色会变黑不可读。
5. **占位符**：封面「汇报人/指导老师/日期」、第 5 页姓名学号，交付前必须替换。
