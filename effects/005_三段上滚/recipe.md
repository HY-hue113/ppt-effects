# 效果5 · 三段上滚

> **参考件状态（2026-11-07）**：背景换成作者的草原照，12 个孤儿媒体（含 mp3/wav）与 28.9MB 嵌入字体已删，文档属性改为 `ppt-effects`。正文原用「思源宋体 CN Light」，剥离字体后由使用端回退；要锁定字形请自带该字体。

来源：`哲学-什么是真实的存在.pptx` 第 17–19 页。三页共用一张照片背景，正文分三段随翻页向上滚动，配大号章节号「01」与一条弧形装饰线。

## 结构

| 页 | 内容 |
|---|---|
| 1 | 标题「什么是「存在」」+ 第一段（真正的"存在"…） |
| 2 | 整体上滚：标题上移出画，露出第二段 |
| 3 | 继续上滚：第三、四段进入画面 |

- 背景：整页照片（`p:bg` blipFill）
- 底块：`矩形 4` 纯色（铺满），压在照片上做统一色调
- **转盘/弧形**：freeform（custGeom），`useBgFill="1"` 即**幻灯片背景填充**——它透出的是没被压暗的原图，所以画面上会出现一片比周围亮、边缘只有描边的"取景窗"。这是设计，不是 bug：**不要改成无填充**，改了亮窗就没了。起点 (-13, -2.22)，23.64×23.49 cm，另带描边 + 阴影
- 大号「01」：文本框，左侧边缘出血
- 正文：多个文本框，位置逐页改变（第 2 页 y 变负、第 3 页再上移）——这就是"滚动"的全部实现
- 切换：三页均"平滑（按对象）"，`p14:dur="1500"`

### 出画规则（2026-11-07 用户明确）

**该在画布外的文本框必须整体在画布外，不许露出一行、一角。**

- 下一页要出现的段落：整体落在 `y ≥ 页高`（19.05cm）之下等命，例如 y=19.38 起；
- 已经滚走的段落：整体退到 `y + 高度 ≤ 0` 之上，例如 y=-7.24、高 5.81（底边 -1.43）；
- 判定不是"看起来差不多"：逐框算 `y` 与 `y+h` 和 `[0, 19.05]` 的关系，只有当前段落与标题、01 允许在画布内。
- 换文案后先按实际行高重算 `GAP`，再据此推三页的 y；不要靠肉眼挪。

## 坑

1. **"滚动"不是动画**，是三页里同一批文本框的 y 坐标不同；改文案长度后要重新推三页的 y，否则会露白或压字。
2. **正文压标题是原设计**：第 3 页正文从「存在」二字上飘过，参考稿即如此，不要当 bug 修。**但"压标题"与"乱入"是两回事**：仍在画布内的段落可以压字，已经该退场的段落必须整体出画（见上「出画规则」）。
3. **转盘是幻灯片背景填充（`useBgFill="1"`），不是无填充**：这是一条被写错过两次的坑——早先 recipe 写的是"无填充、只有描边"，按它改成 `<a:noFill/>` 会把那片"取景窗"一起改没（2026-11-07 用户纠正）。只有 `<a:ln>` 与 `effectLst` 是对的，但形状本身靠背景填充透出原图。
4. **三页共用一个媒体**：替换一次即可。
5. **删文本框必须先处理 `<p:timing>`**（2026-11-07 实测）：原稿每页的 timing 里挂着 `spTgt spid="2/4/10"` 等引用（属于「」引号与标题的入场动画）。一旦删掉这些形状而留下 timing，PowerPoint 会直接报「文件已损坏、无法打开」（错误码 0x80070570），而 python-pptx 照样能解析，极容易误判成 zip 或媒体的问题。要么保留形状、要么整块删 timing；本效果靠几何位移 + 平滑切换，删 timing 不损失主体效果。
6. **亮窗的对比由蒙版决定**：`矩形 4` 是 50% 黑，参考件底图暗所以窗内窗外界限柔和；换成亮照片后窗会明显发亮。想弱化就调高蒙版透明度（实测 65%–70% 既保窗又保白字），**不要**去动 `useBgFill`。

## 复用到新素材

换 `IMG` 指向的图片；文案改动时同步调三页文本框的 y。标题与「01」的位置不需要动。
