# 效果6 · 加载指针

来源：`动画.pptx` 第 1 页（单页开场）。深色照片背景 + 大标题 + 一个「加载指针」组合，分七段变速旋转，最后百叶窗退场。

## 结构

| 对象 | 说明 |
|---|---|
| 矩形 8 | 铺满页面的纯色底（压在照片上） |
| 文本框 7 | 标题「喀纳斯湖畔」，4.33,4.15，27.42×6.16 cm，行楷 |
| 组合 10 | 指针：3 个矩形 + 1 个椭圆，-16.96,-34.69，70×70 cm（远超画布，只露出中段） |
| image1.jpeg | 背景照片（1200×900），作为幻灯片背景 |

## 动画时间轴（核心）

| 顺序 | 类型 | 参数 |
|---|---|---|
| 0 | 标题淡入 | 单击触发，1.5 秒 |
| 1 | 陀螺旋 | +270°，1000ms |
| 2 | 陀螺旋 | −540°，1000ms |
| 3 | 陀螺旋 | +540°，1000ms |
| 4 | 陀螺旋 | −420°，1000ms |
| 5 | 陀螺旋 | +300°，1000ms |
| 6 | 陀螺旋 | −210°，1000ms |
| 7 | 陀螺旋 | +60°，750ms |
| 8 | 组合退出 | `barn(outVertical)` 百叶窗 |

七段累计 **0°**（270−540+540−420+300−210+60），转完回到起点，所以像"加载转圈"而不跑偏。

## 制作方式：模板移植 + 时间轴补丁

1. 整页继承（形状、组合、文字、时间轴都不动）
2. 只替换 `ppt/media/image1.jpeg`（1200×900，居中裁切）
3. 如需把第一个陀螺旋改为「在上一动画之后」：运行 `tools/patch_effect6_timing.py`

## 坑

1. **组合远超画布**（70×70cm，左上角在画布外），这是故意的：只让指针的一段露出来。不要"修正"尺寸。
2. **旋转角度必须总和为零**，否则每循环一次会累积偏移；改角度时记得配平。
3. **首段触发**：原稿是"单击触发 + 延迟 2000ms"；改"在上一动画之后"要把组级 `delay=indefinite` 改成 0、`nodeType` 改 `afterEffect`，同时把首段自身也改成 `afterEffect`，只改一处不生效。
4. **静态预览看不出转动**，只能看起始帧（指针垂直、标题偏暗），节奏必须实机验。

## 复用到新素材

换 `IMG` 与标题文案即可；旋转角度/时长写在 `spec.json`，要调节奏就改那里再重跑补丁。
