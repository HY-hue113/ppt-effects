# 效果19 · 情景演绎（双版本）

## 一句话

13 页「电话对话 → 五张招式卡」的情景演绎，提供**抠图版**与**免抠图版**两种参考件，按用户素材决定用哪版。

## 两版差别

| | 抠图版 | 免抠图版 |
|---|---|---|
| 主体 | 透明 PNG，独立图层 | 与背景合成在一张照片里 |
| 素材要求 | 透明主体 5–6 个 + 背景 2–4 张 | 普通照片 5–6 张 |
| 每页图层 | 6–7 张（多 1–2 张抠图） | 4–6 张 |
| Morph 观感 | 人物跟着镜头动，层次强 | 整体缩放平移，层次弱一档 |
| 页数 / 文字 | 完全相同 | 完全相同 |

## 调用前必问（写进 skill 流程）

> 「你有没有抠好的透明 PNG 主体图？」
> - 有 → 抠图版，并说明需要 5–6 个透明主体 + 2–4 张背景
> - 没有 / 不想抠 → 免抠图版，只需 5–6 张普通照片

## 结构

| 页 | 内容 |
|---|---|
| 1–3 | 开场：电话铃响 / 您好 / 我在看早报（纯文字+背景） |
| 4–8 | 对话推进：每页 2 行中英台词 |
| 9–13 | 五张招式卡：春秋蝉 / 定仙游 / 万我 / 逆流河 / 大爱仙尊 |
| 切换 | p4–8 淡入淡出 700ms、自动 1500ms；p9–13 Morph slow、自动 1000ms |

## 换素材

1. 选版本 → 打开对应 `reference/参考件-*.pptx`
2. 抠图版：右键主体 PNG → 更改图片（保持透明）；背景图同样替换
3. 免抠图版：直接替换 4–6 张照片，注意主体居中
4. 台词：每页两行（中 + 英），英文长了缩字号，别换到第三行

## 坑

- 抠图 PNG 有白边 → 深色背景上会露白，必须先去白边
- 免抠版照片裁切位置决定观感，主体要居中偏上
- 低版本 PowerPoint 没有 Morph，招式卡只剩淡入淡出

## Morph 关联组命名（2026-11-23）

同一张照片会在多页出现（报纸页褐调版 → 卡片页原色版 → 带白边框），三者的**对象名必须一致**，
Morph（byObject）才会把它们当成同一个对象做平滑位移；名字不同就变成“消失 + 出现”。

| 形态 | 命名 | 说明 |
|---|---|---|
| 报纸页 / 卡片原图 | 关联1 … 关联5 | 同组同图，跨页同名 |
| 加 20 磅白边 | 关联x白边 | 白边版专用 |
| 抠图层（透明 PNG） | 关联x-扣 | 抠图版专用 |

| 组 | 覆盖页 |
|---|---|
| 关联1 | p4–p8、p9 |
| 关联2 | p4–p8、p9、p10 |
| 关联3 | p4–p8、p10、p11 |
| 关联4 | p4–p8、p11、p12 |
| 关联5 | p4–p8、p12、p13 |

**注意**：画布外的同名对象（如 p9 右侧 x=2476 那张）是给下一页做平滑起点用的，**不要删**。
## 出画提醒（2026-11-27）

参考件里有**整块停在画布外**的形状（等命 / 入场用）。这是设计的一部分：

- 按 `--roundtrip` 跑质量门（本库的正常用法）→ **出画放行，不报错**；
- 只有默认/创作模式的版面契约会判 `exceeds the root viewBox`。真要在那条路径下保留出画，
  用 `tools/stage_offscreen.py` 加 staging 豁免。

详见 `effects/005_三段上滚/recipe.md` 的「出画与质量门」一节。
