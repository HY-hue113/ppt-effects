# 效果2 · 玻璃碎片散开

来源：`示范.pptx` 第 5–7 页。素材：一张横构图照片。成品：3 页，"平滑"切换 2 秒，四块"玻璃"从中心叠起 → 散开放大 → 排成一行，标题与目录依次出现。

## 做了什么

- 第 1 页：照片铺满 + 30% 黑遮罩；4 个「图文框」叠在中心（旋转 43.9°），只有投影可见。
- 第 2 页：4 块玻璃散开、放大到最大 18.4cm、各自旋转；标题「开学」/「快乐」96pt 行楷白色浮现。
- 第 3 页：玻璃落成一行 5cm 小方块；「目录」72pt + 01–04 各 60pt。
- 三页之间使用"平滑（按对象）"，`p14:dur=2000`（2 秒），单击触发。

## 关键机制：玻璃是"幻灯片背景填充"

图文框（`prstGeom prst="frame"`）**不能**填照片，必须 `useBgFill="1"`，同时把照片设为幻灯片背景（`p:bg` 的 blipFill）。这样框内显示的是背景本身、与背景完全重合，视觉上只剩投影——玻璃才有"透明玻璃"的观感。若给框填图片，会变成一堆彩色菱形（第一次就是这么翻车的）。

## 归一化规格

见 `spec.json`：玻璃每页的 `[x, y, cx, cy, rot, adj1]`、遮罩透明度、文字位置字号、切换时长。

## 制作管线

```bash
# 1. 建项目
python project_manager.py init <名称> --format ppt169 --quick-generate --dir <工作区>/projects

# 2. 三页 SVG：底图 + 30% 黑矩形 + 文字（不要画玻璃）
#    注意质检器不接受超画布元素，文字位置先写终态
python svg_quality_checker.py <项目> --quick-generate --canonical-authoring --stage final --json
python svg_to_pptx.py <项目> -f ppt169 --quick-generate -t none -o <导出>.pptx

# 3. 补丁：底图转背景填充、插入玻璃、修文字、加切换
python <本技能>/tools/patch_effect2.py --in <导出>.pptx --out <定稿>.pptx
```

## 踩过的坑

1. **必须先 `useBgFill` + 幻灯片背景**，否则玻璃变成彩色菱形（见上）。
2. **行距是 90%**：导出器写死 115.5pt，示范继承版式的 90%，不改会让两行标题相差 27px。
3. **标题用段内换行 `<a:br>`**，两段会多出行距。
4. **编号 01–04 的锚点比几何中心低约 15px**（1280 画布），`spec.text.page3.numbers_y_offset` 已补偿。
5. **图片引用**：玻璃用背景填充后，不需要为每页额外插入图片关系，文件也更小（653KB vs 1371KB）。

## 复用到新素材

换 `images/bg.jpg` 与文字即可；玻璃的几何、阴影、切换全在 `spec.json`，不需要重调。照片比例不必 16:9，背景会拉伸铺满。

# 长版（19 页，2026-10-31 增补）

同一套玻璃语汇向下延伸成完整段落，来源为 `示范.pptx` 第 5–23 页（46 页新稿）。调用效果2 前**先问用户要短版还是长版**。

## 长版结构

| 页（原稿编号） | 段落 | 说明 |
|---|---|---|
| 5–6 | 玻璃开场 | 四块玻璃 + 标题「开学快乐」 |
| 7–8 | 目录 | 「目录」+ 01–04 |
| 9–15 | 分段 01–04 | 每段一个章节号，玻璃做转场 |
| 16–23 | 四栏拼贴 | 4 张竖条照片 + 大号 1/2/3/4 + 中文标签 |

切换全部为「平滑（按对象）」，时长以原稿为准（0.6–2 秒），未另行修改。

## 长版制作方式：模板移植

1. 以用户**最新稿**为源（用户会随时改稿，务必重新读桌面文件，不要用旧副本）
2. 只保留原稿第 5–23 页，其余页与其 rels、notes、Content_Types 一并删除
3. 逐个识别图片槽位：对每个媒体算色彩指纹，与素材比对取最近邻，再按槽位尺寸居中裁切替换
4. 文字、形状、切换、视频原样继承

脚本：`tools/build_effect2_ext.py`

## 长版的坑

1. **必须现读用户文件**：这次因用了 3 小时前的旧副本（30 页 vs 46 页）整份重做。每次先比对哈希/页数。
2. **槽位识别用色彩指纹**：不能靠顺序猜，按均值+方差最近邻匹配，距离 >500 的需人工确认。
3. **媒体跨页共用**：如 `image8` 被 17 页引用，替换一次即可。
4. **页数不固定**：由用户稿子的段落范围决定，范围变了脚本里的 `KEEP` 要跟着改。

## 长版扩展：背景按页段 + 四栏换图 + 去标签（2026-11-01）

用户可能只给"几张图 + 对应页段"，此时按下面三条处理：

1. **背景按页段替换**：用户说"这四张图是背景（1–6 / 7–12 / 13–18 / 19）"，就按输出页号分区间替换。
   - 背景有两种存法，必须都兼容：前段是"铺满页面的图片形状"（spPr 里带 blipFill），后段是"幻灯片背景填充"（`p:bg` 里的 blipFill）。
   - 原稿常有多页共用同一个媒体，**不能直接替换媒体**，否则全篇串味；要给每一页单独生成媒体部件 `ppt/media/bgpNN.jpg` 并新增关系，把该页的 blip 指过去。
2. **四栏拼贴页的栏内图是内容、不是背景**：只换背景的话这几页看起来没变。需要按栏位（x 从左到右）各放一张，媒体是全页共用的，替换那 4 个媒体即可。
3. **栏下标签要跟着内容走**：换图后原标签（盘山/喀纳斯/国门/草原）会失配；用户选择"删除标签、只留数字"时，按文本内容匹配 `<p:sp>` 整块删掉。

脚本：`tools/build_effect2_ride.py`（含上述三条的完整实现）。

> 判定"哪个是背景"的可靠办法：先找尺寸≈整页（12192000×6858000，容差 20 万 EMU）且带 `a:blip` 的形状；找不到再退到 `p:bg//a:blip`。
