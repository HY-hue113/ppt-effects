# 效果18 · 摄像机动态转场（NO.190）

## 一句话

三层图层固定不动，靠**遮罩组合旋转 + Morph 自动换片**做出"镜头甩动"的转场观感。

## 成片形态

7 页、1280×720、只有 1 行副标题；三张图从头用到尾，页面之间只变"镜头角度"。

## 结构

| 层 | 位置（px） | 尺寸 | 说明 |
|---|---|---|---|
| 底图 | 0,0 | 1279×720 | 全屏横构图照片 |
| 中部横幅 | 231,92 | 852×293 | 主标题/大字形，建议透明 PNG |
| 底部装饰 | 0,527 | 1280×192 | 红绸、地面、色带 |

## 动效参数

| 项 | 值 |
|---|---|
| 切换 | Morph（byObject），spd=med，advTm=750ms（自动换片） |
| 末页 | spd=slow，dur=1250ms |
| 遮罩旋转 | p4 60° → p5 240° → p6 300° → p7/p8 90° |
| p2 额外 | 3 条运动路径（0→0.25 页高，500ms）+ 2 个旋转强调 |

**关键**：图片本身的位置/尺寸/crop/rot 全程不变，视觉变化全来自遮罩组的角度，Morph 把角度插值成镜头运动。

## 替换素材

1. 底图：换全屏横构图照片（1280×720 或更大，16:9）
2. 中部横幅：换透明 PNG（大字/标题图形）
3. 底部装饰：换色带/地面装饰
4. 副标题：≤20 字，一行

## 坑

- PowerPoint 2019 以下没有 Morph → 效果消失（只留普通切换）
- 三层图色调不统一时，旋转过程接缝明显
- 横幅不透明会盖住底图
- 自动换片 750ms 是调好的节奏，别随意改快
