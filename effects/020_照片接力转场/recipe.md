# 效果20 · 照片接力转场

## 一句话

三张照片接力：一张先以小图出现 → 下一页铺满成为背景 → 下一张在画布外待命 → Morph 平移放大进场 → 循环，最后 THANK YOU 收尾。

## 关键：图片对象 vs 背景图片填充

| 形态 | 实现 | 出现位置 |
|---|---|---|
| 图片对象 | `<p:pic>`，可放画布外待命 | p5 小图、p6 起画布外右侧/上方、p8 起的移动 |
| 背景图片填充 | 幻灯片背景 `p:bg` 里的 `blipFill` | p6/7、p10/11/12、p15/16 |

**两者是同一张照片的两种承载方式**：上一张照片"接棒"的方式就是从图片对象变成整页背景。
所以换图时必须**同时**替换图片对象用的媒体和背景用的媒体。

## 对象命名关系

| 名称 | 含义 |
|---|---|
| 图片 1 | 照片A，首次小图（p5） |
| 图片 2 | 照片B，p6–p9 从右侧画布外移入 |
| 图片 3 | 照片C，p10–p14 从上方画布外移入并放大 |
| !!1 / !!2 / !!3 | Morph 配对标记对象（`!!` 前缀） |

## 页面流程

| 页 | 内容 |
|---|---|
| 1–4 | 标题结构页（色块排版，PRESENTATION） |
| 5 | 照片A 小图 218×351 |
| 6–7 | 背景＝照片A；照片B、C 在画布外（x=1362 / 1741） |
| 8–9 | 照片B 移入（572→525, 139×240 → 232×400） |
| 10–12 | 背景＝照片B；照片C 在 y=-487 待命 |
| 13–14 | 照片C 移动并放大到 1278×732 |
| 15 | 背景＝照片C |
| 16–18 | THANK YOU（照片C 背景 + 纯色收尾） |

## 换图要点

1. 三张照片，每张要准备两份：4:3（图片对象/多数背景）与 16:9（p12、p16 背景）
2. 画布外的对象不要删、不要挪，改名也会断开 Morph 配对
3. 文字只有 标题1/2/3 + THANK YOU，可直接改

## 背景填图：每页都不一样（2026-11-25 用户说明）

参考件里**每个“背景图片填充”页用的都是不同的图**：

| 页 | 关系 |
|---|---|
| p6 / p7 | 不同（不是同一张的重复） |
| p10 / p11 / p12 | 三页互不相同 |
| p15 / p16 | 不同 |

合计 7 个背景位 + 3 个图片对象位 = 至少 7–10 张图；**只给 3 张照片必然出现重复**。

### 填图前必须先问

1. 「p6 和 p7 都是内容页，背景填图要一致吗？」
2. 「p10 / p11 / p12 要各不相同，还是允许同一张？」
3. 「p15 和 p16 要一致吗？」
4. 「照片不够时，同一张用不同裁切充当不同背景，可以吗？」

默认按“每页各不相同”处理；用户说可以重复时，才允许复用同一张。

## 实测版（2026-11-25，用户认可）

参考件已换成园林版：7 张照片各就各位，背景位互不相同。

| 位置 | 照片 |
|---|---|
| p5 小图 + p6 背景 | 竹林小径 |
| p7 背景 | 亭廊 |
| p8–p9 移动 + p10 背景 | 月门白墙 |
| p11 背景 | 圆洞门 |
| p12 背景（16:9） | 树影水面 |
| p13–p14 放大 + p15 背景 | 水榭 |
| p16 背景（16:9） | 玉兰 |

经验：园林/景区类照片天然适合这个效果——门、廊、径本身就有入口的语义，配 p8–p14 的门形取景更顺。
## 出画提醒（2026-11-27）

参考件里有**整块停在画布外**的形状（等命 / 入场用）。这是设计的一部分：

- 按 `--roundtrip` 跑质量门（本库的正常用法）→ **出画放行，不报错**；
- 只有默认/创作模式的版面契约会判 `exceeds the root viewBox`。真要在那条路径下保留出画，
  用 `tools/stage_offscreen.py` 加 staging 豁免。

详见 `effects/005_三段上滚/recipe.md` 的「出画与质量门」一节。
