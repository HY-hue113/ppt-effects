# 效果9 · 金边弧线（19 页）

来源：`镶金边职业生涯(12).pptx`。白底 + 深蓝大弧线 + 圆形取景 + 超大数字，切换统一"慢速 + 2 秒"，并开启**自动换片 2 秒**。

## 读到的参数

| 项 | 值 |
|---|---|
| 尺寸 | 33.9 × 19.1 cm（16:9） |
| 页数 | 19 |
| 切换 | 多数页 `spd="slow"` + `p14:dur="2000"`（2 秒慢速） |
| 换片 | 每页 `advTm="2000"` —— **自动 2 秒换页**（不需要点击） |
| 动画 | 仅第 2 页（目录）有 8 个淡入/浮入；其余页靠切换推进 |
| 图片 | 16 张，横竖混排：1920×1080 / 1422×800 / 976×1145（竖） |
| 版式 | 白底、深蓝弧线贯穿、圆形/胶囊取景、章节页大数字 01–04 |

## 版式语言（复用要点）

1. **弧线**：一条深蓝粗弧从页边切入，是最有辨识度的元素，任何新页都要保留
2. **取景**：照片放在圆形或半圆里，不是满版；照片与形状用"图片填充/相交"而非裁切贴图
3. **数字**：章节页用极大字号（200pt+）配英文副标
4. **留白**：正文区大量留白，字少、行距大

## 复用方式

模板移植（mode A）：整份继承版式与切换，只换图片与文字。

### 槽位与用图（2026-11-07 修正）

- 固定 **16 个媒体槽**，不是 5–16；`spec.json` 里 `materials.min/max = 16`。
- **少于 16 张可以重复使用**：`deficit: repeat` + `allow_repeat: true`，`check_materials.py` 会提示“缺的 N 个槽位会重复使用你给的这 M 张（不会混入旧图）”，不再视为阻断。
- 画幅不匹配按 **居中裁切** 处理（`crop_allowed: true`），不是拉伸；1.33 的图进 1.78 槽会裁掉约 25%。
- 竖槽只放竖图，横槽放横图——方向不对时宁可裁切，也不要把竖图拉成横幅。

```bash
# 1) 换图：按槽位尺寸居中裁切后替换 ppt/media/*，保持文件名与尺寸
# 2) 换字：python tools/prefix_texts9.py  （占位文字 + 按页面明暗自动配字色）
```

## 占位文字规则（用户约定）

- 字号 ≥ 28pt 视为标题 → `标题：请输入文本`
- 其余视为正文 → `正文：请输入文本`
- **字色随页面明暗**：页面平均亮度 < 130（暗底）用白色，否则用黑色
- 文本框设 `word_wrap=False`，避免 5 个字折行压版

## 坑

1. **自动换片 2 秒**是这个模板的节奏核心，删掉后"慢速切换"就白设了——改页数/内容时别顺手关掉。
2. 部分页本来就是"标题 + 正文"两行紧贴，统一成占位文字后会显示两行"标题：请输入文本"，属正常，填文案时改掉即可。
3. 大数字页的文本框很窄，直接塞长文案会破版；这类框要单独放大或缩短文案。
4. 竖图槽位只有 1:1.17 左右，横图硬塞会被裁掉两侧——按方向分配素材。
