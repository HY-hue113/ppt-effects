# 效果7 · 环形开场（25 页 = 开场 8 页 + 内容 17 页）

来源：用户亲手调校的 `效果7.pptx`（2026-11-04 版，现为 25 页整套）。这是**黄金参考件**，形状与刀片宽度都由用户手工调过，脚本只允许替换素材，**禁止重建刀片几何**。

## 页面结构

| 页 | 内容 |

| 1 | 环形扫光开场：24 片「幻灯片背景填充」刀片 + 24 片黑片，黑幕在下、刀片居中透出照片 |
| 2 | 圆形取景：大圆 + 4 张图片 + 十字分割线 |

**开场 8 页（1–8）共用 `image1.jpeg`（1200×900）；整套 25 页去重后共 13 张媒体**（image1–image13，含 1 张 675×900 竖图、1 张 4096×3072 大图、1 张 626×354 小图）。只做开场就只换 image1；做整套要 13 张逐一替换。

## 关键参数

| 项 | 值 |
|---|---|
| 刀片 | 24 白（`useBgFill`）+ 24 黑，贝塞尔圆角楔形，每片 8 个控制点 |
| 动画 | 每片 1 个 `presetID=23` 缩放进入（宽高动画 `p:anim`），48 个效果 |
| 节奏 | 延迟 200 / 340 / 480 / 620 …（**步长 140ms = 单次时长 140ms**），匀速 |
| 背景 | `p:bg` 图片填充（设置背景格式），不是图片形状 |
| 层级 | 背景（p:bg）→ 黑幕矩形 → 白刀片 → 黑刀片 |

## 复用到新素材

**只做开场 8 页**：把 `ppt/media/image1.jpeg` 换成新图（居中裁切到 1200×900），其它一律不动。

**做整套 25 页**：13 张媒体逐一替换，**每张按它自己的原始像素做覆盖裁切**（竖槽 675×900 要竖构图，大图 4096×3072 别缩成小图再放大），刀片、切换、时间轴一律不碰。四字标题按**位置**映射（左上/右上/左下/右下），不要按对象顺序套字。

```bash
python tools/build_effect7.py --in reference/效果7.pptx --image <新图> --out <输出>.pptx
```

## 坑（重要）

1. **禁止用脚本重建刀片**：它们由 `moveTo/cubicBezTo/lnTo/cubicBezTo/close` 组成，是圆角楔形；按"四点+圆心"的方式重算会压成退化形状，页面直接变黑。用户已手工加宽过缝隙，改形状请让用户在 PowerPoint 里用「编辑顶点」做。
2. **黑片必须与白片同源**：任何位置/尺寸差异都会让边缘露白。历史上黑片曾整体偏移 5819 EMU 导致露边。
3. **延时步长必须等于单次时长**（140ms）：否则会出现"越转越慢"。曾因外层包装累加延迟（200→450→750…）出现这个问题。
4. **静态预览看不到内容**：开场页黑片在终态，打开是黑的，必须按 F5。

## 改文字的经验（2026-11-05 实践总结）

1. **字号 ≠ 角色**：48pt 在第 8/12/16/20 页是章节名，在第 9/10/11 页是别的东西；72pt 与 44pt 两个框常常紧贴，长文案必然互相压。只能按页建映射表，不能只按字号分档。
2. **不要用 f.clear()**：会丢掉 run 的颜色（主题色/白字变黑）。正确做法是**原地改 run.text**，保留 rPr。
3. **必须递归进组合**：shape_type == 6 要 walk(shape.shapes)，否则组合内的文本框全部漏改。
4. **跳过用 continue，不能用 return**：判断大字不动时若 return，会把该页后面所有对象一起跳过——第 8 页整页空白就是这个 bug。
5. **PART ONE / CONTENTS 要先拦**：它们是 20pt，会落进正文分支被覆盖。这类标记的判断必须放在字号分档之前。
6. **成对页文字必须同源**：8↔9、12↔13、16↔17、20↔21 是平滑切换的两态，同一套文案写两遍；否则切换时文字会跳。
7. **画布外不是错误**：第 8 页文字被拖到可视区外，是为了 morph 从左滑入。看到空白页先问是不是故意的。
8. **文案长度要匹配框宽**：72pt 框 ≤4 字；44pt 英文 ≤1 个词；14–16pt 正文 ≤6 字；24pt 卡片 ≤4 字。超了必折行压版。
9. **参考件只读**：reference/ 里的文件不要覆盖，输出到桌面或 preview。曾把用户手改的参考件覆盖，无法还原。
10. **小批量验证**：一次改 3 页 → 渲染 → 确认 → 再继续。全量 100+ 处一次写入，出错时无法定位。
