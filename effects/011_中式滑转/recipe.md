# 效果11 · 中式滑转（多图版）

> 基准件：`reference/效果11.pptx`（4 页模板，ppt-master 模板套用版）
> 多图成品：`reference/效果11-多图版.pptx`（9 张图 → 10 页）
> 生成脚本：`tools/eff11_multi.py`

## 一、层级关系（自上而下，第 n 页，n≥2）

```
文本框组合(n-1) → 纯色填充小色块(n-1) → 标题(n-1)文本框 → 正文(n-1)文本框
→ 文本框组合 n → 纯色填充小色块 n → 米色纯色填充小色块
→ 图片填充小色块(n-1) → 图片填充小色块 n
```

第 n+1 页整体顺移一位。**形状不重建，按模板复制页得到**。

## 二、严格对应法则（仅本效果适用）

- 同一名称的对象：填充方式与内容相同
- 不同名称的对象：填充方式与内容不同
- 具体：`小四边形副本K图` ← 第 K 张图；`小四边形副本K` ← 第 K 号颜色

## 三、位置规则

若「文本框组合 x + 纯色小色块 x」与「图片填充小色块 x」在当前页分居两侧，
则下一页两者互换位置——模板本身已按此规律（p2 与 p3 就是一组镜像）。

## 四、页数与末页（关键）

| 条件 | 末页布局 |
|---|---|
| 图片数 a 为**奇数** | 色左 + 字左 / 图右（把 p5 的两块与文字组移到左边） |
| 图片数 a 为**偶数** | 保持 p5 原样：色右 + 字右 / 图左 |

页数 = a + 1（封面 + a 个图页）。

## 四之二、a = 1 的情形

只有 1 张图时：页数 = 2（封面 + 单图页）。
单图页没有「上一张」，因此只有一块图片填充小色块；布局按奇数末页规则：
**色左 + 字左 / 图右**，编号 1。

## 五、复制页做法（避免动画守卫）

1. 以 p2（图右）与 p3（图左）为骨架交替复制
2. 复制后**重编形状名**为目标索引（副本K图 / 副本K）
3. 按名填图、按页上色（纯色块强制 `solidFill`，不保留 `schemeClr`/`gradFill`）
4. 背景色 = 该页纯色块颜色，二者同源
5. 末页按第四节规则处理

## 六、编号

正文页左下/右上组合里的数字 = **页序 − 1**（P2→1、P3→2 … 末页 = a−1）。

## 七、文字颜色

- 组合（竖排标题）：白色，落在纯色块上
- 文本框 21/22：深色，落在米色板上

## 八、图片复用：不允许

本效果**不支持复用**。每张图只用一次，调用时不再询问复用范围。
页数固定 = a + 1（封面 + a 个图页）。

## 九、坑

1. **动画守卫**：直接改 SVG 删形状会触发 `removed source animation target`；只能复制页 + 改名 + 换填充
2. **组合是 `grpSp`**：改文字组位置要遍历 `<p:grpSp>`，不是 `<p:sp>`
3. **交换坐标要先取值再赋值**，否则两块重叠
4. **纯色块可能用主题色**（`schemeClr accent1 lumMod`），必须清空后重建 `solidFill`
5. 本地渲染只能看静态帧，出场动画需在 PowerPoint 播放确认
