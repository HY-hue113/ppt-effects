# 效果1 · 湖景斜切滑入

来源：`示范.pptx` 第 3–4 页。素材：一张 4:3 风景照。成品：2 页，第 2 页"平滑"切换 1 秒，文字自左、斜切色块自右滑入。

## 原始步骤（用户口述，原文保留）

1. 新建第一页 ppt，将素材拖入，拉伸至与背景边缘重合；图片格式 → 颜色 → 颜色饱和度 0% → 艺术效果 → 虚化。
2. 插入矩形，黑色填充，33.87×2.03 cm，置于页面最上方；复制一个置于最下方。
3. 插入文本框（数量/内容/字体/字号按询问），调整文本。
4. 选中第一页整体，Ctrl+D 复制为第二页。
5. 第一页：所有文本框向左平移至视口外（参考示范第 3 页参数）。
6. 第二页：再次拖入素材铺满；插入平行四边形（置于顶层）；先选图片再选平行四边形 → 形状格式 → 合并形状 → 相交；设置图片格式 → 效果 → 阴影（参数同示范第 4 页）；线条 → 无线条。
7. 复制第二页的平行四边形到第一页，向右平移至视口外。
8. 第二页：切换 → 平滑 → 持续时间 1 秒 → 单击时。

## 归一化规格（机器可执行）

见 `spec.json`。关键值：

| 对象 | 起始（视口外） | 结束（画面内） |
|---|---|---|
| 标题 | x=-13.80 cm, y=2.86 cm | x=3.81 cm, y=4.06 cm，框 14.96×4.36 cm |
| 斜切图 | x=35.35 cm，宽 10.46 cm | x=19.39 cm，宽 11.07 cm，满高 19.05 cm |

- 平行四边形按对象外框归一化：上边从 0.25w 起，下边到 0.75w 止（两者都向内缩 25%）。
- 阴影：黑色 40%，模糊 4pt，距离 3pt，方向 45°，对齐 tl。
- 切换：`p159:morph option="byObject"`，`spd="slow"`（=1 秒），单击触发，只加在第 2 页。
- 背景：灰度 + 轻虚化（示范稿原始图 3297 px 宽时约 4 px，等效 2364 px 宽约 3 px），全幅拉伸。

## 制作管线（ppt-master）

```bash
# 1. 建项目（quick 模式，无需 design_spec）
python scripts/project_manager.py init <名称> --format ppt169 --quick-generate --dir <工作区>/projects

# 2. 素材：灰度+虚化底图、按 spec.crop 预裁并预压扁的斜切图，放进 images/
# 3. 两页 SVG 都按"终态"写（起点的两个对象先放画面内），放 svg_output/
# 4. 检查 + 导出
python scripts/svg_quality_checker.py <项目> --quick-generate --canonical-authoring --stage final --json
python scripts/svg_to_pptx.py <项目> -f ppt169 --quick-generate -t none -o <输出>.pptx

# 5. 精确校正（关键）：把第 1 页对象按 spec.start 移出画布、第 2 页对齐 spec.end、
#    补 outerShdw、给第 2 页写 morph 切换
python <本技能>/tools/patch_effect.py --in <输出>.pptx --spec <本目录>/spec.json --out <定稿>.pptx
```

## 踩过的坑（下次必须注意）

1. **质检器拒绝超画布文本**：起点态若直接把 text 写在 x<0，`svg_quality_checker` 会以 `viewBox issues` 报错并退出 1。必须两页都写终态，导出后用 patch 移出画布。
2. **东亚字体回退**：SVG 写 `font-family="华文行楷"`，导出后 `a:latin` 正确但 `a:ea` 会被写成 Microsoft YaHei，必须 patch 成同一字体，否则中文不显示行楷。
3. **艺术效果不可移植**：a14 的 `artisticBlur` + `saturation` 在 ppt-master 里没有对应能力，改为 Pillow 预渲染并烘焙进图片（示范稿内部其实也存了渲染后的图层，视觉一致；区别是 PowerPoint 的"艺术效果"面板里看不到这一项）。
4. **斜切图必须预压扁**：形状是窄高平行四边形，若直接放原图会被拉伸；按 `spec.crop` 先裁再压到 418:720 比例，成品才与示范一致。
5. **morph 靠对象名配对**：两页的 `Image 5` / `TextBox 6` 名字必须一致，否则平滑切换会退化成淡入淡出。
6. **`option` 只能是 `byObject`**（2026-11-07 实测）：`p159:morph option="object"` 不是合法枚举，PowerPoint 会在打开时直接报"无法打开文件"（整个包被判定无效），而 python-pptx / 其它工具都读得出来，极易误判成别的错误。`spec.json` 的 `transition.morph_by` 已改回 `byObject`。验收时务必用 PowerPoint COM 真开一次，别只信 python 解析。

## 复用到新素材

替换 `images/` 里的照片与标题文案即可，位置、阴影、切换参数都从 `spec.json` 读，不需要重新调。

### 素材亮度（2026-11-07 增加）

标题是**黑色**压在灰度虚化底图上，所以底图不能太暗。`spec.json` 的 `materials.checks.text_contrast` 定了阈值
`min_mean_luma: 140`：`check_materials.py` 测到平均亮度低于 140 会直接警告，并给出三条修法——

1. 标题改白字（`layers.title.color` 改 `FFFFFF`，同时把斜切图的阴影方向/浓度看一眼）；
2. 底图加一层 30%–50% 的浅色遮罩（在白字方案下不需要）；
3. 换一张亮调图。

实测：暗调插画（平均亮度 55）套进来，黑字几乎看不见；这一步必须在动手前提示用户，不能默默出稿。

## 标题变体：短标题（≤2 字）

4 字标题用默认参数即可；**2 字及以下必须走 `short` 变体**，否则会显得偏左、偏小：

```bash
python tools/patch_effect.py --in 导出.pptx --spec spec.json --out 定稿.pptx \
       --text 草原 --variant short
```

`spec.title_variants.short` 的定义：

| 项 | 值 | 说明 |
|---|---|---|
| 字号 | 144pt（默认 96pt） | 两字时视觉重量与四字标题接近 |
| 水平 | 居中于左侧可视区 | 区域 0–733px（斜切带左缘），中心 x=366px |
| 垂直 | 字形中心 y=235px | 与四字版参考件的**实测**墨迹中心一致，不是画布正中，也不是行盒正中 |
| 文本框 | x=9, y=91, 700×300 px | 以 PowerPoint 渲染实测反推 |

**注意**：CSS/DrawingML 的居中是对"行盒"居中，CJK 字形墨迹并不在行盒正中。实测偏移随字体、字号、字对（笔画高低）而变，必须渲染后量，不要凭公式推。

量法（本机已验证）：PowerPoint COM 把两页各导出 1920×1080 PNG，两页相减（第 1 页标题在画布外、第 2 页在内），取差异墨迹 bbox 的中心，再换算回 1280×720。`盘山`@144pt 华文行楷实测：行盒中心 (375,231) → 墨迹中心 (382.7,225)，即墨迹相对行盒 +7.7 x / −6 y；所以要落在 (366,235)，盒子必须给 (9,91)。

> 2026-11-07 校正：原 `box_px` 25/81（声称落在 366,251）实为公式推算值。用 1920×1080 实测，四字参考件 `喀纳斯湖` 的墨迹中心是 (405,235)，不是 251，故一并改为与实测对齐。
