# 效果10 · 暗红塔影（11 页）

## 素材硬门槛（2026-11-07）

主体图有**两种合法输入**，二选一：

1. **白底原图**（自己拍的剪影、产品图、白底导出的 PNG）：流程是「亮度反推 alpha」，白底像素被判为背景；
2. **已经处理好的透明 PNG**（对方抠好、去底完成的图）：直接染色即可，跳过反推。

除这两种之外（暗调满版、有场景背景的图）做不出线稿——会整片变黑、脏边明显。

spec.json 里 checks.white_bg_blocking: true —— check_materials.py 测到边缘白底占比 < 0.75 会**直接阻断**（退出码 1），不是警告。实测暗调插画占比 0.00，进来做不出线稿。

checks.accept_alpha: true 让 checker 认透明通道：实测一张 79% 透明的 PNG 直接 PASS（备注“已是处理好的主体图”）。对方给的是哪种，先跑 check_materials.py 效果10 <图> 就能判定；不确定就先跑一遍。


来源：教程视频 `adcd4071…mp4`（4 分 44 秒）+ 素材 `tu.png`（白底塔图）。入库版本为用户手改后的 11 页稿。

## 坑

1. **导出器不写 morph**：`animations.json` 里声明了 transition，导出后 `slide.xml` 里没有 `<p:transition>`，必须用 `inject_morph.py` 补。已验证效果1、2、10 都这样。
2. **白底图必须去白**：直接用会在深红底上留一块白方块。按亮度反推 alpha 并染色，同时裁掉原图底部的水印带（`tu.png` 右下有小红书号）。
3. **形状筛选别只看尺寸**：先按 `prst == 'roundRect'` 过滤，否则会把同尺寸的 `Ellipse` 光晕也改成矩形（我踩过，第 2 页光晕被改成方块）。
4. **改长条形状只换 `prst`**：位置/尺寸/填充/文字都不动，`prstGeom` 的 `avLst` 要清空后重设 `adj`。
5. **黑底要用 `addprevious` 插入**，保证在长条之下、文字之上，不能用 `append`。
