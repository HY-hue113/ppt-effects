# 效果14 · 立体图片轮播

**基准件**：`reference/效果14.pptx`（11 页 / 10 标签，用户手改版，22 MB）
**方式**：`template-clone` —— 复制基准件后按规则换图、减标签、隐藏多余文字
**生成器**：`tools/eff14_gen.py`（改 `IMGS` 与 `OUT` 即可，N 自动推导）

## 结构

| 区域 | 内容 |
|---|---|
| 顶部 | 深色条 + 标签 01–10（圆角高亮块 + 当前页编号高亮） |
| 主体 | 每页一张大图（17.4 × 9.8–10.9 cm）；相邻页大图停在画布外 |
| 左下 | 缩略图（5.7 × 3.2 cm）；上一页缩略图停在画布外左侧 |
| 左侧 | 标题 / 副标题 / 正文（morph 推拉） |
| 背景 | 满页底图（`p:bg` 图片填充） |

## 换图规则（已用用户实例验证）

**页数 = N + 1**（1 页开场 + N 个图页），k = 页序 − 1

| 页 | A 大图(画布内) | B 小图(画布内) | C 小图(画布外左) | D 大图(画布外右) |
|---|---|---|---|---|
| P1 开场 | — | — | 图1 + 图2（重叠） | — |
| Pk (k≥1) | 图 k | 图 k+1 | 图 k+2 | 图 k−1 |

- 越界（<1 或 >N）→ 该图位移出画布（y = −50 cm）
- 图位几何：A x≈15.7/y≈4/w17.4｜B x≈0/y≈15.8/w5.7｜C x≈−6/y≈15.8/w5.7｜D x≈37/y≈4/w17.4

## 标签（只减不增）

- 模板 10 个标签，**只能隐藏不能新增**（新增会与原文本对象冲突）
- 减到 N 个：`x = SLOT*(n-1) + SLOT/2 - w/2`，`SLOT = 33.87/N`，`y = 1.4cm`
- 多余标签：`y = −20cm` 移出画布

## 高亮块

- 中心对齐激活编号：`x = nx + nw/2 − hw/2`，`y = ny + nh/2 − hh/2`
- **P1（无激活）**：移到画布外左上 `x = −6cm`，`y` 与 P2 高亮顶端一致（0.93cm）

## 文字重叠（关键）

每段文字有两个形状，内容相同：

| 形状 | 角色 | 处理 |
|---|---|---|
| `TextBox 12` | 标题（大） | 保留 |
| `TextBox 13` | 标题（小副本） | **隐藏** y=−40cm |
| `TextBox 14` | 正文（大） | 保留 |
| `TextBox 15` | 正文（小副本） | **隐藏** |

不隐藏就会出现「标题2 / 标题2」「正文2 / 正文2」重影。

## 坑

1. **`p:pic` 的图片不在 spPr 里**：路径是 `p:pic/p:blipFill/a:blip`；按 `spPr/blipFill` 查会静默空转（本次耗了 3 轮）
2. **背景图在 `p:bg`**：替换 `p:bg/a:blipFill/a:blip` 的 `r:embed`，靠改 rels 的 Target 换图
3. **重复源页要给独立 svg 名**：`page_plan` 里同一 `source_slide` 出现两次会报 `pages[N].svg repeats`
4. 画布外元素是 morph 推拉用的，**不要删**，只能改图片指向
5. 缩略图 `y=16cm` 高 3.2cm 会超下沿（基准件已修，注意别改回去）

## 调用流程

1. 问：要几个标签 / 几页（≤10，只减不增）
2. 问：每页用哪张图（可重复）
3. 跑 `tools/eff14_gen.py`（N = 图片数）
4. 需要更少标签时手动隐藏多余编号 + 对应图页
