# 效果18 · 图片取景形状

**基准件**：`reference/效果18_图片取景形状.pptx`（6 页，示范 5 种基本形状 + 4 种组合）
**方式**：`shape-mask` —— 用形状遮罩把图片"截"成各种轮廓，再叠一圈描边

![总览](preview/总览.png)

## 一、五种基本形状

| 形状 | 轮廓 | 适用 |
|---|---|---|
| `cut` **切角** | 左上 18% 切角 | 稳、偏正式，适合方案/论文 |
| `circle` **圆形** | 正圆 | 人像、特写、柔和 |
| `hex` **六边** | 六边形 | 有节奏、偏现代 |
| `arch` **拱形** | 上圆下方（门洞） | 建筑、门、洞穴、"入口"意象 |
| `diag` **斜切** | 平行四边形 | 动势、前后对照 |

实现：先生成**与形状同轮廓的透明 PNG**（PIL 遮罩），再把同形状的描边叠在图上。这样在 PPT 里图是图片、框是形状，都能单独换。

## 二、四种组合（本次示范）

| 组合 | 页 | 规则 |
|---|---|---|
| **同形同尺寸并列** | P1 | 5 张 200×200，间距 = 宽 16%；一张图一个形状 |
| **同形不同尺寸** | P2 | 主图 380 + 辅图 180×2；同族形状靠尺寸分主次 |
| **异形叠压** | P3 | 六边 420 + 圆 240 压角；后图加 6px 白描边分层 |
| **多图阵列** | P4 | 1 大（420×300）+ 4 小（190×140），同形同距 |
| **异形对置** | P5 | 斜切 460 + 拱形 380，中间留 150px 竖缝 |
| **同形阶梯** | P6 | 切角 380→300→220 沿对角线递减 |

## 三、参数

| 项 | 值 |
|---|---|
| 切角量 | 短边 × 18% |
| 六边斜边 | 短边 × 22% |
| 拱形圆角 | 短边 × 45%（只圆上两角） |
| 斜切偏移 | 宽 × 20% |
| 描边 | 2–3px，强调色；叠压时后图用白描边 6px 分层 |
| 图间距 | ≥ 宽 × 12%（小于这个会挤） |

## 四、使用流程

```
1. 选形状与尺寸 → 用 tools/build_demo.py 里的 mask()/crop() 生成透明 PNG
2. 同尺寸形状的描边用 outline() 生成（几何与遮罩同源，不会错位）
3. 放进页面：图在前、描边在后
4. 一页最多两种形状；超过两种，视线会散
```

## 五、纪律

1. **一页最多两种形状**，且必须一主一辅；
2. 同页多图必须**同形同尺寸**（除主图外）；
3. 叠压时后图必须加**白描边**，否则两张图的边界会糊在一起；
4. 拱形只用于竖向构图，横图塞进拱形会裁掉太多。

## 六、可扩展

- 新增形状只需在 `mask()` 里加一个分支（如菱形、胶囊、波浪边、票券齿孔）；
- 组合方式可继续加："三形咬合""网格 + 一个异形破格""同图多种形状并置对比"。

## 排版坑（2026-11-13 实测）

1. **标题/副标题会折行**：ppt-master 导出的文本框宽度按字数估算，略紧
   - 解法：要么把文案压到 6–8 字，要么导出后把**顶部标题框**加宽（只加宽 y < 3.3cm 的框，别动底部标签和描边）
2. **加宽要挑对象**：一次性加宽所有形状会把描边多边形拉成横跨全屏的线
3. 底部标签用 	ext-anchor=middle，加宽文本框会让文字整体右移，居中就失效了

## 组合边框（2026-11-14）

单一形状不够用时可组合：把多个形状（可不同）以不同尺寸/位置画进同一张遮罩取**并集**，
再用并集边界截图与描边。示例组合：拱形+底条、切角+缺口、双圆、六边+竖条、切角+内框线。

同一份 PPT 里，同一种边框单独使用**最多 2 次**，多出的用组合边框补齐。
