# 文框（文本底卡 + 文本框样式）

> text-tools 三分类之一：**文框**。占位文字统一用「文本」。

## 一、内容

| 文件 | 说明 |
|---|---|
| `reference/文框-样式集.pptx` | 50 种文本框样式（来自《PPT设计排版》第 17–23 页），共 7 页 |
| `reference/文框-分页-52.pptx` | **分页版**：52 页，每页一个样式，编号 文框001–文框052 |
| `preview-split/文框001.jpg …` | 分页版每个样式的独立预览 |
| `styles.json` | 编号 ↔ 原页 / 形状名 / bbox |
| `preview/` | 预览图 |

分页版用法：直接复制对应编号的那一页。编号按原 7 页的阅读顺序（从上到下、从左到右）排列；52 个是实际可用的完整样式数（原 README 的 50 为约数）。

样式集规则（两层占位）：
- 页内**较大字号**（≥页内最大字号的 70%）→ 「标题」
- 其余 → 「文本」
- 数字序号保留（如 `01 文本`）
- 形状全部原生可编辑，未烘焙成图片

# 文本底卡处理区 · Text Tools

> 跨效果复用的**文字容器库**。给标题、正文、要点提供多样的底卡与标签，避免"一堆字直接压在页面上"。

## 一、这里有什么

| 文件 | 作用 |
|---|---|
| `tools/card_lib.py` | 生成卡片类素材：`card()` 底卡 / `chip()` 胶囊条 / `tab()` 标题标签 / `badge()` 序号块 |
| 本文件 | 样式说明、组合规则、调用方式 |

## 二、四种底卡

| style | 外观 | 适用 |
|---|---|---|
| `plain` | 白底 + 细边 + 轻投影 | 默认，最稳 |
| `tint` | 浅蓝渐变 + 细边 | 需要一点层次时 |
| `bar` | 白底 + 左侧金色竖条 | 正文块、要点列表 |
| `line` | 只有细边、无填充 | 叠在图片上（不遮图） |

另有三种文字容器：

| 函数 | 外观 | 适用 |
|---|---|---|
| `chip()` | 胶囊条 + 左侧圆点 | 单行要点、标签式列表 |
| `tab()` | 深蓝书签 + 金色底线 | **小标题专用** |
| `badge()` | 圆角方块 + 金边 | 序号 01/02/03 |

## 三、三条规则

1. **小标题与正文不共用一张底卡**
   - 小标题用 `tab()` 或 `badge()+chip()`，独立成块
   - 正文另起卡片
2. **正文不一定要一张大卡**
   - 3–4 条要点 → 每条一张 `chip()`，纵向排列
   - 4 条以上 → 2×2 或 2×3 网格，每格一张 `card()`
   - 只有长段落才用一整张 `card(style="bar")`
3. **同款卡片在同一份 PPT 里避免泛滥**
   - 参考图片边框的做法：同款用 ≤2 次，靠 `plain / tint / bar / line` 与尺寸差异轮换

## 四、调用

```python
import sys
sys.path.insert(0, r'<LIB_ROOT>\text-tools\tools')
from card_lib import card, chip, tab, badge

tab('t.png', 220, 46)          # 小标题标签
chip('c.png', 420, 40)         # 单行要点
card('k.png', 460, 180, style='bar')   # 正文卡
badge('b.png', 44)             # 序号块
```

生成后在 SVG 里 `<image href="...">` 引用，文字用 `<text>` 叠在卡片上。

## 五、与图片处理区的关系

- `image-tools/` 决定**图**怎么被框住
- `text-tools/` 决定**字**怎么被承托
- 两者可组合：文字卡叠在图片边缘（`line` 款不遮图）

## 六、维护纪律

**新增样式必须同步更新样式集**（`reference/*-样式集.pptx`），否则工具区没有可视化说明。
同 `image-tools` 的做法：一份示范 pptx + 按页预览图。

## 八、混排拓展方向（P6 路线）

同一页里让不同容器承担不同角色，避免整页一种卡：

1. **标签 + 胶囊 + 强调卡**（P6 现有）：小标题 / 若干要点 / 一个结论块
2. **网格 + 侧图**：2×2 网格卡在左，取景图在右（SQTP 稿已采用）
3. **时间轴胶囊**：chip 竖排 + 左侧细线 + 圆点，做时间安排
4. **数据强调块**：card(tint) + 大号数字（40–56pt），做预算/人数
5. **引文卡**：card(line) + 引号 + 出处，做访谈摘录

拓展时同步加示范页，保持一页一用法。

## 十、三类容器的可变体（2026-11-14）

同一用途不必只用一种形状；**按页面情况选形式**，别把 P7–P9 当成唯一答案。

### 时间轴

| 变体 | 形式 | 适用 |
|---|---|---|
| 竖向直线 + 胶囊 | 细线 + 圆点 + `chip` | 页高、条目 4–5 条 |
| 横向直线 + 胶囊 | 横线 + 圆点 + 上方 `chip` | 页宽、条目 3–4 条 |
| 曲线 + 小圆点 | 弧线/波浪线 + 小圆点 + 短标签 | 想弱化“流程感”、版面更松弛 |
| 阶梯折线 | 折线 + 圆点 + 日期在折点上 | 阶段性强、有明显跃迁 |

要点：**线可以弯，点可以小，胶囊可以换成纯文字标签**；时间轴的核心是“顺序可见”，不是“必须有胶囊”。

### 引文卡

| 变体 | 形式 | 适用 |
|---|---|---|
| tint 整卡 | 浅蓝底 + 引号 + 出处 | 常规摘录 |
| 左侧金条卡 | `card(bar)` + 引号 | 想更学术、更克制 |
| 半透明叠图 | `card(line)` 或半透明白卡压在图下缘 | 图文混排、访谈现场照片 |
| 单句大字 | 无卡，仅大号斜体 + 出处 | 一页只用一句“金句” |

### 数据强调块

| 变体 | 形式 | 适用 |
|---|---|---|
| 方卡三连 | `card(plain)` + 大数字 | 3 个并列指标（现 P9） |
| 圆形指标 | 圆 + 大数字 + 环线 | 比例类、单一主指标 |
| 数字 + 单位上标 | 数字大、单位小 | 预算/金额（1890.60 元） |
| 横向数据条 | 数值 + 条长表示量级 | 多项对比（交通/印刷/宣传） |

### 使用纪律

1. 同一份 PPT 里，同类容器**不要连续三页同一形式**——换一种变体即可
2. 变体之间保持字体、金色、圆角半径一致，只换“承托方式”
3. 新增变体时，同步在样式集里补一页

## 十一、三条使用纪律（2026-11-14 追加）

1. **引文卡不单独使用**——必须与其他文本搭配：引文压上半，下半配 2–3 条要点胶囊；
   单独一张引文卡会让整页显得空。
2. **时间轴日期放在线外**（线的左侧或胶囊上方），不要塞进胶囊里，否则和事项挤在一起。
3. **数据块与合计条之间留 30px 以上**，否则合计条像“贴”在三块下面，层级不清。

## 十二、字号与引文卡前提（2026-11-14 追加）

- **正文 ≥20pt**：低于 20pt 不合格；装不下就减少字数或加大容器，不要缩字号
- 引文卡：**不单独使用**，同页需配 ≥2 条要点；卡片宽 ≤560、高 ≈150，引文 18pt 可略小
- 时间轴：日期在**线外**；竖/横、直/曲按版面选

## 十三、底卡分类：主类型 + 分型（2026-11-14）

**方框上的修饰不算新类型，只算分型。**

| 主类型 | 用途 | 分型 |
|---|---|---|
| 方卡 | 通用正文块 | plain / 	int / ar / line / **corner 折角** / **duo 双线** / **topbar 顶条** |
| 胶囊 | 单行要点 | 带圆点 / 纯色 / 描边 |
| 标签 | 小标题 | 书签式 / 顶部色条式 |
| 网格卡 | 并列要点 | 2×2 / 2×3 / 带序号 / 不带序号 |
| 引文卡 | 摘录 | tint / bar / 叠图 / 单句大字 |
| 数据块 | 指标 | 方卡三连 / 圆形 / 横条 |
| 时间轴 | 顺序 | 竖向 / 横向 / 曲线 / 折线 |

新增分型只需在 card_lib.py 的 style 分支里加一条，**不必新建主类型**。

## 十四、混排版式（推荐）

一页里让容器各司其职，比整页一种卡更耐看：

`
左侧 强调卡（tint）  ── 主结论，2 行以内
右侧 2–3 条胶囊      ── 支撑要点
`

已用于 SQTP 的「成果形态」「调查观察」两页。注意：卡内文字 20pt、胶囊 18pt，
超出可用宽度时**截断而不是缩小字号**（字号下限 20pt 优先）。

## 十五、定稿版式：三卡 + 宽幅图 + 说明板（2026-11-14，用户 P12 微调后）

编号坐标（1280×720 画布，直接照抄即可）：

| 元素 | 位置/尺寸 |
|---|---|
| bar 卡 ×3 | x=198，y=212 / 348 / 488，w=358，h=118 |
| 卡内文字 | x=237（卡左 +39），20pt，单行或折两行 |
| 宽幅取景图 | x=635，y=357，**514×165**（横向宽画幅，不是方图） |
| 说明板 | 贴在图上，w≈420、h≈86，深色 #12212E 透明度 0.48 |
| 板上文字 | 17pt 白字，两行，左对齐 |

要点（这版为什么好看）：
1. **三块卡而不是两块**——填满左侧竖向空间，不空
2. **图是宽画幅**（3.1:1），与三块卡的“横向节奏”一致，不抢戏
3. **说明板压在图上但只占一部分**，不是整张盖住，图还能读
4. 卡与图的面积比约 1:1.1，视觉平衡

反面教材（前一版）：图只有 330 宽、说明板几乎盖满整图 → 图变成一条缝，板变成灰块。


## 十六、版式封装 `layouts.py`（2026-11-14）

一次调用拿到整页形状清单，配 `emit()` 写入 spTree：

```python
from layouts import timeline, datablocks, quote, emit

emit(spTree, timeline([("2026.11", "文献研读"), ("2027.01", "实地踏勘")]))
emit(spTree, datablocks([("425.45", "交通费")], total_text="合计 425.45 元"))
emit(spTree, quote("引文一句", ["正文一", "正文二"]))
```

| 函数 | 产出 |
|---|---|
| `timeline` | 竖线 + 圆点 + 胶囊 + 日期（4 项约 9 个形状） |
| `datablocks` | n 张数字卡 + 可选合计条 |
| `quote` | 小引文卡 + n 张正文卡 + 序号块 |

参数全部带默认值、**都可覆盖**——按文案与版面调，不写死。

## 三层细化（2026-11-15 补充）

数字圆标上的装饰性小字（原为竖排小标签）按 **B 方案**处理：
- 保留「标题」占位，但字号压到 **8pt**（宽 < 90px 的标题框统一处理）
- 目的：不遮挡数字序号，同时不删除任何对象

## 装饰小字处理（2026-11-15，三类统一）

部分样式在"主文字"之外还有一层装饰性小字（常见于数字圆标、角标、竖排小标签）。
统一按 A 方案处理：**保留「标题/文本」占位，但把宽度 < 90px 的窄框字号压到 8pt**，
既不遮挡数字序号，也不删除任何对象、不破坏结构。

> 更宽的装饰字（>90px）仍保持原字号——这类通常是样式本身的第二层标题，属正常设计。

## 浅色残留：保留为撞色（2026-11-15 定案，方案 B）

智能换色后，原稿的浅粉/浅色描边会残留成"浅蓝偏白 + 一点原色"的淡彩。
**按用户意见保留**——这类撞色在版面上起到点缀作用，不做进一步压平。

- 需要完全统一时：用 `recolor_styles.py`（定点映射，压平所有浅色）
- 想保留撞色层次：用 `recolor_smart.py`（按色相换主色，浅色保留明度关系）
