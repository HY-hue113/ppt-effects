# text-tools · 文本相关三大类

| 分类 | 目录 | 占位文字 | 内容 |
|---|---|---|---|
| **标题** | `title/` | 标题 | 100 种标题样式（5 页） |
| **导航栏** | `nav/` | 标题 | 40 种导航栏样式（8 页） |
| **文框** | `textbox/` | 文本 | 50 种文本框样式（7 页） |

来源：`桌面\PPT设计排版（标题、导航栏、文本框）.pptx`，已按类拆分成三份可编辑稿，文字占位化、数字序号保留。

## 共同规则

1. 形状全部**原生可编辑**，不烘焙成图片
2. 占位文字：标题类用「标题」，文框用「文本」
3. **数字序号保留**（`01`、`02`…）
4. 使用时复制所需样式的页面，替换占位文字

换色：`tools/recolor_smart.py`（按色相，保留浅色撞色）/ `tools/recolor_styles.py`（定点压平）

装饰性窄框小字统一压到 8pt（见各分类 README「装饰小字处理」）。

各分类细则见各自 README。
